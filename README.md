# TransmissionBar

A native **macOS menu bar torrent app**, forked from Transmission. Close the panel while transfers keep running; click the icon or use the configurable shortcut to return.

**Version 0.7 is a public beta.** This is built for Apple Silicon Macs.

- [Download a release](https://github.com/FallenPeregrine/transmissionbar/releases)
- [Features, installation and build instructions](TransmissionBar/README.md)
- [Report a TransmissionBar bug](https://github.com/FallenPeregrine/transmissionbar/issues/new?template=transmissionbar-bug.yml)

TransmissionBar's Swift app and packaging scripts are in [`TransmissionBar/`](TransmissionBar/). This fork also preserves Transmission's upstream source and licenses. The menu bar app uses Transmission's local RPC API and is an independent project, not an official Transmission release.

For the original Transmission project's documentation, see [README.upstream.md](README.upstream.md). Existing upstream copyright and licensing notices remain in [COPYING](COPYING) and [licenses/](licenses/).
